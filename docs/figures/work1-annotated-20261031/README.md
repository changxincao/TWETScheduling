## 数学与几何核对

示例J3取p3=4、[e3,d3]=[10,18]。左侧执行位置为[4,8]、[16,20]，对应E3=2或T3=2；右侧执行位置为[8,12]、[16,20]，对应EW3=2或TW3=2。六项任务的完整输入见 [source-data.json](source-data.json)。这是可行示意，不代表最优排程，也不是实验结果。

凸费用取α=1、β=1.5、γ=δ=2、u=v=2，其从左到右斜率为−3、−1、0、1.5、3.5，已由分段函数及相邻顶点斜率独立核对。加工量费用按实际加工区间与窗口外区间求交，逐点核验min截断式；工作量超过p3时不会继续累积。阶跃增量及阈值均在源数据中给出。

主图、左侧示意及两幅费用图的e3横坐标均为354.548571 pt，d3均为539.691429 pt；所有左右窗口的物理宽度均为185.142857 pt。右组采用平移后的时间原点，单位时间比例保持相同，所以p3加工块的物理长度也一致。实测结果见 [coordinate-check.json](coordinate-check.json)，程序对左侧端点重合及所有窗口等宽使用严格断言，差异小于1e-8 pt。

源程序为 [build_work1_aligned_costs.py](../../../scripts/figures/build_work1_aligned_costs.py)，在项目根目录运行`python scripts/figures/build_work1_aligned_costs.py`可重建。已核对可行性、共同坐标、凸性、加工交叠和完整输出；对齐报告PASS，最终PDF无文字互撞、线条穿字或裁剪FAIL，保留透明窗口带边界的10项WARN并人工审阅。PDF最小字形6.65 pt。纵向间隔因主排程、位置示意、公式区承担不同内容而不同，只对这项间隔均等要求作窄范围豁免，窗口端点及绘图区横向对齐仍全部检查。

图与代码均未修改求解算法、论文、实验数据或正式运行。当前尚未按特定期刊栏宽缩排；300 dpi PNG和矢量文件是本轮讲解与审阅产物。

## 名称依据

并行机due-window论文中使用total weighted earliness and tardiness及total weighted number of early and tardy jobs，明确区分时间偏差费用与早晚事件费用。本图数量目标采用该名称，并把多档阶跃注明为推广，未将多档罚金直接冒充普通任务数。参见[Janiak等（2009），第2节](https://www.journals.pan.pl/Content/105838/PDF/02_paper.pdf)。本次名称核对不涉及新颖性或研究贡献评价。
