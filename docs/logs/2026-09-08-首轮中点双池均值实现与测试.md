# 首轮中点双池均值实现与测试

## 1. 实现范围

按用户最终确认规则，维护同node、同active cuts的两个标量池：全部完整首轮的Tmid之和/计数，以及完整F/B耗时比不超过4的样本之和/计数。筛选池非空用其均值，否则回退全部均值；没有完整历史才default。不设最少样本数，不使用区间中心，不做分级probe，不更改probe或adaptive阈值、步长。

每次pricing最多记录一个首轮样本。样本在首轮完整搜索结束后取得，F/B含最终选中probe的可复用扩展与后续扩展，不含废弃候选。后续DSSR轮不覆盖；首轮没完成、预证书直接返回、未运行probe均不产生样本。Phase-I不读写历史。首轮已完成但后续轮超时时，该完整首轮仍可作为历史起点，它不提供任何certificate。

`NgDssrFirstRoundMidpointHistory`采用弱键按Node存储，当前Node未重载equals/hashCode，因而不同trial对象即使node ID相同也隔离。值只包含cuts快照和两个sum/count，不引用node、label、dual或ng-set；cuts改变替换该node的池。`enableNgDssrFirstRoundMeanStart`默认false，本机JVM属性`twet.bpc.midpointFirstRoundMean=true`开启，与旧的最终轮缓存实验互斥。历史起点仍经过当前probe合法范围裁剪。

## 2. 验证与实验约定

定向javac编译通过；双池回归覆盖空池、fallback、单样本、4边界、刚超过4、零/NaN/无穷时间、无效中点、节点隔离、cuts快照及失效；原probe配置和策略回归通过。日志`seedSource=firstRoundMean:filtered/fallback:allN:qualifiedK`表明当前使用的历史和样本数。

测试选择random/base/zero：n50-set01/m2、n40-set01/m3、n50-set01/m4。zero为窗宽不是zero setup。每个基线和双池均值各跑两次完整BPC，第一次baseline→mean，第二次反序。共享上一批ALNS seed，正式NG_DSSR、Arc，1800秒安全上限、maxNodes100000，未关闭启发式/强分支/root preprocessing，所有Cplex保持原正式单线程设置。本机串行，两远端正式运行未修改。

复现脚本`scripts/experiments/run-midpoint-mean-20260908.ps1`；冻结`93685d4a`jar加本次编译覆盖类，目录`.codex-tmp/midpoint-mean-20260908/classes`。完整输出在同一目录各run子目录；统计使用`analyze-midpoint-start-20260908.ps1 -WorkDir .codex-tmp/midpoint-mean-20260908`。共享seed位于上一批`.codex-tmp/midpoint-reuse-20260908/`，指纹见上一专题。总时间不含共享seed生成。

## 3. 完整结果与判断

12次全部FINISHED、gap0、排程可行和目标重算一致，无时限截断。配对配置快照仅输出路径和本次开关不同。完整汇总保存于`docs/logs/data/20260908-midpoint-mean-local.csv`。

两个短例始终每次首轮只试1点，无重复候选可省。n40/m3均值15.731→16.667秒，略慢约6%；n50/m4均值24.712→24.499秒，基本不变，不应宣传普遍提速。

## 4. 实际日志验收与后续边界

n50/m2双池两遍分别70/64次使用筛选均值，没有fallback；n40/m3分别18/17次fallback，n50/m4各5次fallback，实际运行覆盖两条路径。样例：node4首轮完整ratio4.611后，下一次all11→12而qualified维持10，证明不合格点只进入全部池，且多轮DSSR没有按轮重复计数。该规则也可能让旧合格均值维持不变并重复移动，这是当前设计的已知性能局限，不擅自加窗口或改变阈值。

默认继续关闭，远端代码和运行未改。当前只验证3个random/base/zero算例，不包含family、宽窗及n80/100；也未单独分离“首轮匹配”“均值”“筛选”各自贡献。本批支持在重复probe开销大的案例继续验证这一组合，不支持直接更改所有正式运行。
