# Work 3 时间界与大 \(M\) 预处理规格

日期：2026-09-06

本文件固定两个基础模型共用的时间界计算口径。以 2026-09-06 最新聊天记录为准：先计算最细的任务—位置界 \(\underline C_{jk\omega},\overline C_{jk\omega}\)，再分别聚合得到 P-W 的位置 horizon 和 2-index 的任务界。PDF 中单独构造的粗 \(H_{k\omega}\) 只保留为校验或低成本 fallback，不再作为已经计算 \(\overline C_{jk\omega}\) 时的首选实现。

## 1. 基础量

定义任务转移增量

\[
\tau_{0j\omega}=s_{0j\omega}+p_{j\omega},\qquad
\tau_{ij\omega}=s_{ij\omega}+p_{j\omega}.
\tag{B1}
\]

由于 \(a_j\le U_j-D_j^{\min}\)，所有窗口左端的公共上界可取

\[
\overline A=\max_{j\in J}\{U_j-D_j^{\min}\}.
\tag{B2}
\]

免费等待虽然允许任意延长，但累计等待超过 \(\overline A\) 后可以截断而不增加 earliness，并且只会减小 tardiness。因此至少存在一个最优代表解，其累计等待不超过 \(\overline A\)。下列完成时间上界限制的是这个最优代表域，不是所有含任意冗余等待的原始可行 timing。

记 \(p^{\uparrow}_{-j,r,\omega}\) 和 \(p^{\downarrow}_{-j,r,\omega}\) 分别为除任务 \(j\) 外第 \(r\) 小和第 \(r\) 大的加工时间，并定义

\[
\overline s^0_\omega=\max_j s_{0j\omega},\qquad
\overline s_\omega=\max_{i\ne j}s_{ij\omega}.
\tag{B3}
\]

## 2. 任务—位置下界

在允许重复任务的放松网络中递推最短 walk：

\[
b^{\min}_{1j\omega}=\tau_{0j\omega},\qquad
b^{\min}_{kj\omega}
=\min_{i\ne j}\left\{b^{\min}_{k-1,i,\omega}+\tau_{ij\omega}\right\},
\quad k\ge2.
\tag{B4}
\]

任务 \(j\) 位于第 \(k\) 位时的完成时间下界取为

\[
\boxed{
\underline C_{jk\omega}
=\max\left\{
b^{\min}_{kj\omega},
p_{j\omega}+\sum_{r=1}^{k-1}p^{\uparrow}_{-j,r,\omega}
\right\}.
}
\tag{B5}
\]

第一项保留具体 setup 结构但允许重复任务；第二项忽略 setup，却强制前面包含 \(k-1\) 个不同任务。二者互不支配，因此下界取最大值。

## 3. 任务—位置上界

在同一放松网络中递推最长 walk：

\[
b^{\max}_{1j\omega}=\tau_{0j\omega},\qquad
b^{\max}_{kj\omega}
=\max_{i\ne j}\left\{b^{\max}_{k-1,i,\omega}+\tau_{ij\omega}\right\},
\quad k\ge2.
\tag{B6}
\]

任务 \(j\) 位于第 \(k\) 位时的完成时间上界采用

\[
\boxed{
\overline C_{jk\omega}
=\overline A+min\left\{
b^{\max}_{kj\omega},
p_{j\omega}+\sum_{r=1}^{k-1}p^{\downarrow}_{-j,r,\omega}
+\overline s^0_\omega+(k-1)\overline s_\omega
\right\}.
}
\tag{B7}
\]

最长-walk 项保留 setup 链，但可能因重复高耗时任务而虚高；另一项保留任务互异的加工时间总量，但把 initial setup 和每段 setup 分别取最大，可能组合出不可同时达到的粗上界。两者均安全且互不支配，因此上界取最小值，最后加上代表解允许的累计等待上界 \(\overline A\)。

## 4. P-W 的位置 horizon：由 \(\overline C_{jk\omega}\) 聚合

先对固定位置 \(k\) 的所有可能任务取最大：

\[
\widehat H_{k\omega}=\max_{j\in J}\overline C_{jk\omega}.
\tag{B8}
\]

\(\widehat H_{k\omega}\) 不一定随位置 \(k\) 非降，而 P-W 的 dummy 尾部需要继承最后一个真实位置的累计时钟。因此最终场景位置 horizon 必须取前缀最大闭包：

\[
\boxed{
H_{k\omega}
=\max_{1\le h\le k}\widehat H_{h\omega}
=\max_{1\le h\le k}\max_{j\in J}\overline C_{jh\omega}.
}
\tag{B9}
\]

P-W 的绝对窗口和 wide dummy 不带场景下标，故采用跨场景公共界

\[
\boxed{H_k=\max_{\omega\in\Omega}H_{k\omega}.}
\tag{B10}
\]

这就是当前实现应使用的 \(H_{k\omega}\) 与 \(H_k\)：不是直接照搬 PDF 中“前 \(k\) 大加工时间 + 每段最大 setup”的粗式，而是先由 \(\overline C_{jk\omega}\) 对任务取最大，再对位置作单调闭包。

作为校验，可计算旧的粗界

\[
H^{\mathrm{coarse}}_{k\omega}
=\overline A+sum_{r=1}^{k}p^{\downarrow}_{r\omega}
+\overline s^0_\omega+(k-1)\overline s_\omega.
\tag{B11}
\]

按式 (B7)–(B9) 有 \(H_{k\omega}\le H^{\mathrm{coarse}}_{k\omega}\)。程序应把该关系作为预处理断言；若不计算最长-walk 上界，式 (B11) 才作为低成本 fallback。

## 5. 2-index 的任务界与大 \(M\)

2-index 不知道任务最终处于哪个位置，因此沿位置聚合：

\[
\boxed{
\underline C_{j\omega}=\min_{1\le k\le n}\underline C_{jk\omega},\qquad
\overline C_{j\omega}=\max_{1\le k\le n}\overline C_{jk\omega}.
}
\tag{B12}
\]

这里必须注意方向：任务级下界取所有位置下界的最小值；任务级上界取所有位置上界的最大值。随后 2-index 的弧大数统一取

\[
\boxed{
M_{ij\omega}
=\max\left\{0,
\overline C_{i\omega}+\tau_{ij\omega}-\underline C_{j\omega}
\right\},\qquad i\ne j,
}
\tag{B13}
\]

\[
\boxed{
M_{0j\omega}
=\max\left\{0,
\tau_{0j\omega}-\underline C_{j\omega}
\right\}.
}
\tag{B14}
\]

若以后使用 incumbent/cutoff 推出更紧的任务完成时间上界，只对 \(\overline C_{j\omega}\) 再取最小值即可；这属于可选动态收紧，不改变以上基础依赖关系。

## 6. 统一依赖关系与实现检查

当前唯一口径为

\[
(\underline C_{jk\omega},\overline C_{jk\omega})
\Longrightarrow
\begin{cases}
H_{k\omega},H_k, & \text{供 P-W 使用},\\
\underline C_{j\omega},\overline C_{j\omega},M_{ij\omega}, & \text{供 2-index 使用}.
\end{cases}
\tag{B15}
\]

实现时至少检查：\(\underline C_{jk\omega}\le\overline C_{jk\omega}\)；\(H_{k\omega}\) 和 \(H_k\) 随 \(k\) 非降；\(\overline C_{jk\omega}\le H_{k\omega}\le H_k\)；\(H_{k\omega}\le H^{\mathrm{coarse}}_{k\omega}\)；将任意枚举整数排程代入后，其无冗余等待代表 timing 均落在对应上下界内。
