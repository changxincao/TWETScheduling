主图为 [PNG](work1-merged.png)、[SVG](work1-merged.svg)、[PDF](work1-merged.pdf)。使用 16×10.8 英寸画布，PNG 为 300 dpi、4800×3240；当前是问题讲解稿，没有按具体期刊栏宽缩排。

图上只用损失函数表达式区分三个目标，不再使用 ET、计数、WORK 分类标题。第一式和第三式均用非减分段函数 g、h 表示；示例采用 g(x)=x+(x−2)⁺+(x−4)⁺、h(x)=1.5x+(x−2)⁺+(x−4)⁺，因此按时间偏差收费的曲线在左右两侧各有三个线性段。第二式为按偏差阈值叠加费用的阶跃函数，用实心和空心端点表示阈值取值。第三式按窗口外实际加工量收费，因此保留两端饱和平台，零损失完工区间为 [17,20]，而非 [12,20]。

共同放大例固定 p₃=5、窗口 [12,20]。提前位置的加工区间为 [4,9]，E₃=3、EW₃=5；拖期位置为 [18,23]，T₃=3、TW₃=3。蓝红括号标完工偏差，蓝红块内着色标窗口外实际加工量。两行是替代执行位置，不是同时执行同一任务。三种函数同样是替代目标，不同时相加。

右侧用小窗口、加工块、黑点、尺寸括号和颜色块解释 e、d、S、p、C、E、T、EW、TW；并补充灰色换型块及其时间／金额，以及外包集合、基准报价和聚合支付。Work 1 窗口给定，因此不出现 A、B、窗口决策宽度界或窗口分配费。主时间轴展示内部任务，外包支付仅在图例交代。

源数据见 [illustrative-data.json](illustrative-data.json)，重建脚本为 [build_work1_merged_figure.py](../../../scripts/figures/build_work1_merged_figure.py)。脚本断言核对包含换型时间的排程可行性、两种执行位置的三类损失值，以及完工在窗口内仍可能存在窗口外加工量的区别。对齐、PDF文字和碰撞检查见同名前缀的 JSON；碰撞 WARN 均为透明背景或块内着色的边界覆盖，已逐项人工查看，未发现文字被遮挡。

另用内置生图模型基于校准图试作版式润色，提示词归档于 [imagegen-prompt.json](imagegen-prompt.json)。[生图试稿](drafts/model-styling.png)误将加工块解释成只能在窗口内加工，并改变了部分时间几何，因此未作为交付主图；主图保留矢量源中经过核对的参数和坐标。未修改论文、求解算法或实验数据。
