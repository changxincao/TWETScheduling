## 1. 问题与画法

主图沿用 Model A：A_j≤e_j≤d_j≤B_j，D_j^min≤D_j=d_j−e_j≤D_j^max。灰色外层约束承诺窗口，不约束实际加工块或强制 C_j≤B_j。窗口设置成本采用当前配图统一口径 K_j=ρ_j(e_j−A_j)+λ_j(D_j−D_j^min)，与原稿 ρ_j e_j+λ_jD_j 仅相差固定常数；图中不报告目标数值。

窗口费与执行费为加性分项，通过 e_j,d_j 耦合，联合优化。原三类曲线仍表示选定窗口后的执行费用 φ_j(C_j;e_j,d_j)，不能把窗口费抬成曲线基线，也不把三类执行费同时相加。每条下层函数图不再重复外层允许范围，避免把窗口端点限制误读成完工时间限制。

A 用位置后移 e−A 与额外宽度 D−Dmin 的尺寸标注直接对应两项费用，是优先尝试的表达。B 用两条过原点的直线展示费用分量和费率，函数横轴分别是位置偏移与额外宽度，信息更明确但小图更多。C 用等宽窗口平移与固定左端点放宽的前后对照展示 ΔK，便于直观看到变化，但会重复出现替代窗口。三个完整提示词见 [prompts.json](prompts.json)。

## 2. Work 3 的接续表达

根据现有问题说明，一阶段决定机器分配、机内顺序与共享窗口；加工时间 p_{jω} 是场景输入，二阶段在既定分配和顺序下调整 S_{jω},C_{jω}，允许场景内等待。“二阶段决策加工时间”的表述应据此解释为工时实现后的执行时刻决策，不把随机工时本身画成可控变量。

后续 Work 3 可保留 Work 2 的窗口可行域与成本横框，仅保留 ET 费用。图上增加“一阶段共享决策 → 工时场景实现 → 二阶段执行时刻”的小流程；用两至三个保持颜色、机器分配和顺序一致的场景排程展示长度变化，共用一组绿色窗口。用户提出的虚影可作为工时波动提示，但仅靠任务两侧虚影无法说明等待和后续任务时刻传播，不应把多个重叠轮廓画成同一场景中同时加工。现主线为线性 ET，凸分段 ET 可作为后续图示推广，需在绘制 Work 3 时沿用户选择明确。
