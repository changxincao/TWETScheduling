## 2. 保留层次，控制拥挤

每项任务固定一种加工颜色；绿线表示任务自己的承诺窗口；灰虚线表示外生可承诺范围；黑点表示加工块右端的完工时刻。窗口细轨与加工块使用同一时间尺度，但分开高度，避免把允许范围、承诺窗口和加工区间叠成难以辨认的一条带。

确定性面板显示全部六项任务的窗口，问题二再补上各项任务的允许范围。只对 J3 标出完整数字与完工连线，其他任务保留短标签。窗口长度上下界放在右侧参数区，避免给每项任务都画四条尺寸线。问题三只突出 J3、J4 的跨场景共同窗口，保留两台机器的场景排程，并列出 J3 的场景工时及完工时间。

三个工作使用同一组承诺值，以便比较结构。问题一将它们视为输入，问题二、三将它们视为已经选定的可行决策；既不表示三个问题最优解相同，也不要求随机模型与确定性模型具有相同最优窗口。三张图对应的是三种替代目标，不把三类偏差费用同时相加。

右侧放大图将 J3 的工时固定为 5、窗口固定为 [12,20]，分别画 C=9、13、23 的三个假设位置。它们用于比较费用，不是同一任务同时加工三次，也不逐一对应左下随机面板的三个工时场景。窗口费只适用于问题二、三，右下纵轴只画偏差费用。

## 3. 费用表达的关键区别

ET 的零费用完工区间为 [12,20]。普通计数按越窗事件收费；多档阶跃版按偏差阈值叠加费用，因此称为分级事件罚金，不直接称作任务数。Early work/tardy work 按加工块在窗口前后的长度收费，在 p=5 时零费用完工区间为 [17,20]，即使 C=13 位于窗口内，也仍有 4 单位 early work。

窗口位置费为 ρ(e−A)，额外宽度费为 λ(D−Dmin)。它们单独列出，不混进偏差曲线。三类曲线均针对图中固定的已选窗口，未画窗口优化后的诱导函数；这样图面始终解释任务和费用，不引入求解方法。

Work 1 完整定义中的 setup 与外包保留在中文数学描述，图中只取内部、无 setup 的共同示例。Work 3 当前正式主线为线性 ET；随机计数、多档事件费和 work 图是问题层面的推广示意，不代表现有实现或历史计算已覆盖这些目标。

## 4. 生成、复核与留存

按此前的生图要求，用内置 imagegen 生成了一张[构图参考](ai-layout-reference.png)，完整提示词保存在 [imagegen-prompt.json](imagegen-prompt.json)。该图用于比较布局，任务下标和 work 着色仍有生成偏差，不作为精确数学图。上面三张主图由 [Python 脚本](../../../scripts/figures/build_due_window_problem_figures.py)依据显式数据绘制，避免生成模型改变时间坐标、阶跃端点或费用曲线。

脚本中的断言核对六项窗口域、三个场景的机器非重叠、C=13 的 ET/work 差别、计数窗口端点，以及加工量分割恒等式 EW+IW+TW=p。所有示例均为可行排程，不求最优。源数据在 [illustrative-data.json](illustrative-data.json)，脚本在项目根目录执行 `python scripts/figures/build_due_window_problem_figures.py` 即可重建主图。

最终几何对齐、PDF 文字、碰撞检查的结果保存在相应 `alignment.json`、`text-audit.json`、`collisions.json` 文件，检查说明见 [qa-summary.json](qa-summary.json)。QA 覆盖层为检查附件，不是最终图。人工复核重点是窗口与加工的对应、跨场景共享、费用分段与跳点、注释遮挡和中文可读性。
