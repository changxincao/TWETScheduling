# NG-DSSR正式批次配置建议

2026-10-19：用户要求根据第二机四变体结果分析后续NG-DSSR正式运行方案。本次只核对本地记录和配置源码，不连接或启动新求解。依据为`2026-09-27-第二机NG-DSSR四变体最终稳健比较.md`及9月28日的补充决定。

## 1. 已测试配置与选择

family的A/B/C/D依次为：Cluster→Arc加全节点scalar TI fixing、Cluster→Arc加root-only、Cluster→supernode CutSet→Arc加全节点fixing、同C加root-only。random只测Arc下全节点和root-only两组。旧family中B相对A共同最优且至少2节点的配对几何时间约下降10.4%；新n50/F3中B/A约1.006，基本持平；random中B/A约0.919。新n50/F3的m4中CutSet将平均节点约175降到86.8，但D/B几何时间约1.025，未形成稳定总时间收益。因此正式主批次建议选择B：family统一Cluster→Arc，random用Arc，关闭CutSet和SuccessorSet，统一root-only。

9月28日另记录了待检验的分层候选：base全节点fixing、medium/high root-only。它不能被当成已经验证优于统一B的正式结论。本轮建议先以统一B补齐算法比较；如果仍要验证该候选，只需在预先固定的base子集补A/B配对，medium/high与B相同，不重复运行。不得逐算例挑四变体最小时间拼成一种算法。

## 2. 算例与模型

先运行纯调度、无外包的NG-DSSR，与TI/TI+SRI使用相同正式输入和已验收共享seed。覆盖n20/40/50/60/80、random/family、全部正式机器数、base/medium/high及zero/narrow/wide窗口。n50/n60 family采用平衡后的F3数据，n80采用当前F4数据；旧F4的n50/n60结果作为历史/消融保存，不混入当前主比较。n100继续暂缓。zero窗口不是zero setup；若以后增加zero setup控制组，分支用Arc。

按现有每规模270个物理算例的设计，n<=60为1080项，n80为270项，单一NG正式配置预计1350项，启动前必须以实际输入索引、TI任务清单和唯一实例键重新核对。现有第二机结果可以用于配置选择；能否作为正式结果复用，须核对代码版本、输入/seed哈希、参数、时限和正常退出证据，不能仅因文件夹存在而跳过。部署采用独立NG输出目录和冻结版本记录，不覆盖既有四变体或TI结果。

## 3. 启动配置约束

以当前命名NG profile为基础，只按setup类别覆盖分支：family打开setup-only Cluster，theta=0.5、temporalWeight=0、strict type priority；random关闭Cluster。root-only设`timeIndexedCompletionBoundNodeArcFixingMaxDepth=0`。根TI预处理、窗口收紧、NG-DSSR自身completion bound、内部弧剪枝和分支传播继续保留。

源码核对确认TIME队列，nearestK初始memory为floor(n/10)，witness候选1000、更新路线20、minimumNewPairsSegment；不开放relaxed columns进入master，不启用memory pair warm-start或allSegments。首轮中点双池均值开启，筛选池完整F/B时间比不超过4，有样本用筛选池均值，否则用全部池均值；active cuts变化时池重置。首轮probe接受比1.5，后续DSSR adaptive触发与probe接受比均4，步长5%，后续probe和最终状态复用保持开启。保留现有ALNS seed、启发式加列及强分支配置，不因批次部署另改预算。

n<=60沿用单项10800秒，n80单项18000秒，均完整树、100000节点上限；最多6个独立JVM，每个模型/CPLEX单线程，具体堆预算须按机器总内存及其他项目占用核对。当前仍在接续TI的第一机应等待该批完成后再安排；第二机是否有其他项目在运行须重新只读检查，不能从旧TWET状态文件推定空闲。本次未指定或启动新的远端队列。

正式启动前冻结当前源码及JAR哈希，核对参数快照、输入/seed一一对应和独立输出位置，做小规模运行验收后再启动。报告最优、时限、失败、未运行数量，并保留总时间、UB/LB/gap、节点、exact/DSSR/probe及fixing时间；主性能表保留根节点闭合项，分支/fixing消融才排除未实际进入对应组件的单节点样本。
