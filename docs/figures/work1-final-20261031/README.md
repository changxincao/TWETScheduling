2026-10-31。用户明确回复“两种都试试”，授权比较完全由生图模型编辑，以及在生图PNG上校正位置、尺寸两种路径。当前推荐[校正版大图](work1-corrected-4k.png)，另有[原尺寸预览](work1-corrected.png)。图保持生图模型的版式、衬线字体、公式和浅蓝标题；未生成SVG。模型底稿为[work1-model-source.png](work1-model-source.png)，纯生图路径的最新结果为[work1-model-direct.png](work1-model-direct.png)。纯生图结果仍把个别J3的完工标签变成C2，且未稳定保持长度，因此不作为推荐稿，不让用户再选版本。

校正版统一六处J3的加工长度，所有J3窗口等宽，左侧主图、完工示意和两幅费用图共享端点；右侧加工量示意与五段费用图也共享端点。所有加工块使用模型原配色的均匀填充，右侧在粉色加工条上边缘用蓝／红短线表示窗口外加工量。主图J1、J5及其余任务的完工点位于各自窗口，J4/J6紧邻，另保留实际空闲段。左侧E/T区间条带与右侧EW/TW加工部分区分展示，不加D3、位置上标或阶跃断点圆圈。图为问题示意，不代表最优排程。

按最新要求，三幅函数图纵轴及底部成本线图例统一使用“成本”；删除“凸分段线性推广”“多档阶跃推广”和相关推广说明，保留英文函数全名及公式。标题栏和外框保持很浅的蓝色。少量轴名和斜率文字用同类宋体／Times字体排清，其他标题、参数与公式字形取自模型底稿。

模型原生尺寸为1448×1086。大图为4344×3258的三倍栅格导出：几何、线条和少量文字按此尺寸绘制，模型原有文字随底图重采样；不能称为模型原生4K或声称恢复了不存在的细节。

校正脚本为[correct_work1_generated_png.py](../../../scripts/figures/correct_work1_generated_png.py)，在项目根目录运行`python scripts/figures/correct_work1_generated_png.py`可复现。它只处理PNG，不使用SVG后端。已检查排程无重叠、六项完工点入窗、凸费用斜率非减、work斜段横向长度等于加工时长、阶跃最后正费用在e3归零。六处J3的实际栅格填色宽度均为293像素，轮廓端点间距均为300像素；各窗口端点间距均为600像素。七处浅蓝标题区域逐像素保持不变，三处公式区域的黑色墨迹保持不变，见[geometry-check.json](geometry-check.json)。已运行输出断言与Python语法检查；未改求解器、论文或实验。
