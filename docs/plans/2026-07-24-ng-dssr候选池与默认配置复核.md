# ng-DSSR 候选池与默认配置复核

## 结论

本次复核的三处问题中，top-C non-elementary witness 池和无 SRI 路径的 SRI 容器分配都是真实的高频冗余；初始历史列重复评价也存在，但只影响初始化，优先级较低。三处均已按不改变求解语义的方式处理。

## 处理

1. top-C 池原先对每条负非基本 route 线性扫描 sequence 判重，插入、替换或同序列成本改善后再对最多 C 条记录全排序。现在改为 `SequenceSignature -> route` 哈希表加按原比较器排序的有界 `TreeSet`。判重、改善和替换为 O(log C)，最差项直接取 `last()`；每轮 labeling 结束后只物化一次有序列表供 DSSR 更新。比较顺序仍为 reduced cost、序列长度、序列字典序；池满时仍只有 reduced cost 严格改善才替换，保持旧阈值语义。

2. no-SRI normal ng-DSSR 在每轮 DSSR 不再创建 cut 列表、memory 列表和 n 个按任务划分的空列表。只有启用 subset-row cut 且使用 SRI-aware partial-list backend 时才初始化这些容器。active SRI 路径不变。

3. `InitialColumnBuilder` 不直接按全局 Pool 命中跳过 evaluator，因为 Pool 允许同 sequence 的更低真实成本原地更新。现在只复用同一次 `build()` 内已经由 evaluator 精确评价过的 sequence ID，避免历史 best 与最终 seed 重复评价，同时保留 Pool 的成本改善语义。

## 默认配置

根据此前完整实验结论，ng-DSSR 相关默认值统一为：nearest 自动 K=floor(n/10)、minimum-segment K20、candidate C1000、source-aware dominance、group-envelope prefilter、visit-profile pruning、allCycles completion bound、midpoint probe、time-indexed root preprocessing、转入最多 200 条 elementary seed、repeatability 初始过滤和 strong branching phase1-only。SRI、RMIH、time-indexed pre-heuristic、warm-start 和 relaxed columns 仍默认关闭；全局定价模式本身也未强制切换为 ng-DSSR。

## 验证

focused `javac` 编译通过；`NgDssrMinimumRepeatedSegmentUpdateTest`、`NgDssrSameNodeWarmStartTest`、`StrongBranchingPhaseOnePricingTest` 均通过。后两项覆盖 no-SRI/SRI 分支入口及 strong repair 定价。当前未做完整算例计时，因此 top-C 优化的实际收益仍取决于困难轮次处理的负非基本 route 数量，但复杂度冗余已经消除。
