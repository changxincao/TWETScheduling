# 三个调度问题的中文数学描述与配图口径

2026-10-31。本文依据三个工作的现有问题描述整理中文定义，并统一配图符号。问题本身与求解方法分开表述；图仅给出可行排程，不表示最优解。Work 1 的 setup、外包和聚合折扣保留在完整定义中，配图只展示三个工作共同的内部调度部分。Work 2 的三类费用已有原始研究材料；Work 3 当前主线为普通线性 ET，图中的随机计数与 work 属于问题定义层面的推广，不能据此称为已实现或已验证的模型。

## 1. 统一符号、窗口约束和三类偏差费用

设任务集合为 \(J=\{1,\ldots,n\}\)，同质并行机集合为 \(\mathcal M=\{1,\ldots,m\}\)。同质是指同一任务的加工时间不因机器标签改变，不要求不同任务具有相同加工时间。所有任务及机器在时刻 0 可用；任务不可抢占，一台机器同一时刻至多加工一个任务。允许首任务开始前及相邻任务之间有非负等待。

确定性加工时间记为 \(p_j>0\)，开始、完工时刻分别为 \(S_j,C_j\)，满足 \(C_j=S_j+p_j\)。任务的承诺完工窗口统一写为 \([e_j,d_j]\)，宽度为

\[
D_j=d_j-e_j.
\]

窗口为输入时，记作 \([\bar e_j,\bar d_j]\)；窗口可决策时，外生允许范围统一写作 \([A_j,B_j]\)，宽度界为 \(D_j^{\min},D_j^{\max}\)。外层范围限制企业能作出的承诺，内层窗口用于评价实际履约。它们不要求加工区间包含于窗口，也不直接要求 \(C_j\le B_j\)。本次采用“承诺完工／可提货窗口”的口径；若解释为实际到货窗口，需要另行说明运输时间如何处理。

### 1.1 两种有界窗口域

Work 2 主稿和 Work 3 当前主线采用的 Model A 要求整个承诺窗口位于允许范围内：

\[
\mathcal W_j^A=
\left\{(e_j,d_j):
A_j\le e_j\le d_j\le B_j,\quad
D_j^{\min}\le d_j-e_j\le D_j^{\max}
\right\}.
\tag{1}
\]

参数满足 \(0\le A_j\le B_j\)、\(0\le D_j^{\min}\le D_j^{\max}\) 和 \(D_j^{\min}\le B_j-A_j\)，从而窗口域非空。可把最大宽度预先替换为 \(\min\{D_j^{\max},B_j-A_j\}\)。Work 2 主稿研究正最小宽度的情形；配套 work 型分析也允许最小宽度为 0。图中选择正的最小宽度，是示例所采用的服务规则。

Work 2 配套材料还研究 Model B：只对窗口起点和长度分别设界，

\[
\mathcal W_j^B=
\left\{(e_j,d_j):
\ell_j\le e_j\le u_j,\quad
D_j^{\min}\le d_j-e_j\le D_j^{\max}
\right\}.
\tag{2}
\]

其中 \(0\le\ell_j\le u_j\)。Model B 的最大右端点为 \(u_j+D_j^{\max}\)，不能把 \(u_j\) 误画成右端点上界。当前三张主图采用 Model A。

上述限制可对应订单允许的承诺范围和可售服务宽度。正最小宽度表示该服务不提供更窄的承诺，需要明确的服务政策；它不等同于加工、装卸或验收的持续时间，也不自动规定端点必须落在离散网格上。

### 1.2 窗口位置费与宽度费

统一用 \(\rho_j\ge0\) 表示位置费率、\(\lambda_j\ge0\) 表示宽度费率。Work 2 原稿的位置、宽度系数分别写作 \(\lambda_j,\eta_j\)，在本文中相应改名，费用本身不变。其原始窗口费用为

\[
\widehat K_j(e_j,d_j)=\rho_j e_j+\lambda_j(d_j-e_j).
\tag{3}
\]

为了和 Work 3 的现有目标、图中的费用说明一致，Model A 也可采用扣除固定基准后的费用

\[
K_j(e_j,d_j)=
\rho_j(e_j-A_j)
+\lambda_j(D_j-D_j^{\min}).
\tag{4}
\]

两者之差为与决策无关的常数 \(\rho_jA_j+\lambda_jD_j^{\min}\)，因此最优决策相同，目标值相差该常数。不能在报告目标值或相对 gap 时混用这两种口径。Model B 若采用同类基准，应以 \(\ell_j\) 代替 \(A_j\)。位置费评价承诺后移，宽度费评价承诺精度降低；它们和实际偏离承诺的费用是不同项。

### 1.3 普通提前／拖期费用：ET

定义 \(x^+=\max\{x,0\}\)。对给定窗口和完工时刻，

\[
E_j=(e_j-C_j)^+,\qquad T_j=(C_j-d_j)^+.
\tag{5}
\]

普通 ET 费用为

\[
L_j^{ET}(C_j;e_j,d_j)
=\alpha_jE_j+\beta_jT_j,
\qquad \alpha_j,\beta_j\ge0.
\tag{6}
\]

固定窗口后，其关于 \(C_j\) 的曲线在左侧线性下降，在 \([e_j,d_j]\) 内为 0，在右侧线性上升。图中蓝色或红色括号标的是完工点与相应窗口端点之间的时间差，并不是加工块中某一段的长度。若合同的单位偏差费率随严重程度变化，可以进一步采用 \(P_j^E(E_j)+P_j^T(T_j)\)，其中 \(P_j^E,P_j^T\) 为从 0 起、非减的分段线性函数。

### 1.4 早到／晚到任务计数，以及多档事件罚金

普通加权计数采用

\[
N_j^E=\mathbf1\{C_j<e_j\},\qquad
N_j^T=\mathbf1\{C_j>d_j\},
\]

\[
L_j^N(C_j;e_j,d_j)
=a_j^E N_j^E+a_j^T N_j^T.
\tag{7}
\]

在端点处按准时处理。只有各任务权重均为 1 时，求和才是早到或晚到任务的数量；一般情况下是加权事件费用。固定窗口后，普通版本的窗口外两侧为常数平台。

用户提出的多档阶跃图可以明确写成

\[
L_j^{GN}
=\sum_{h=0}^{H_E}a_{jh}\mathbf1\{E_j>\tau_{jh}^{E}\}
+\sum_{h=0}^{H_T}b_{jh}\mathbf1\{T_j>\tau_{jh}^{T}\},
\tag{8}
\]

其中 \(\tau_{j0}^{E}=\tau_{j0}^{T}=0\)，后续阈值严格递增，增量费用非负。越过更严重的偏差阈值后叠加罚金。普通加权计数是仅保留阈值 0 的特殊情形；多档版本应称为分级事件罚金，不再把其纵轴直接称作“任务数量”。这是有跳跃的阶跃函数，不是连续分段线性函数；空心、实心端点用于说明阈值处的取值。

### 1.5 Early work／tardy work：窗口外实际加工量

将加工区间 \([S_j,C_j]\) 在窗口前、窗口内、窗口后的长度分别记为 \(EW_j,IW_j,TW_j\)。忽略端点的零长度差别，有

\[
\begin{aligned}
EW_j&=\operatorname{length}\bigl([S_j,C_j]\cap(-\infty,e_j)\bigr)
      =\min\{p_j,(e_j-C_j+p_j)^+\},\\
TW_j&=\operatorname{length}\bigl([S_j,C_j]\cap(d_j,\infty)\bigr)
      =\min\{p_j,(C_j-d_j)^+\},\\
IW_j&=p_j-EW_j-TW_j.
\end{aligned}
\tag{9}
\]

普通 work 费用为

\[
L_j^W(C_j;e_j,d_j,p_j)
=\alpha_j EW_j+\beta_j TW_j.
\tag{10}
\]

这类费用按实际加工量计价，不按完工点的偏差时长计价。任务完全在窗口前加工时 \(EW_j=p_j\)，继续提前也不会增加 early work；完全在窗口后加工时 \(TW_j=p_j\)，继续后移也不会增加 tardy work。因此固定窗口的普通 work 曲线在两端有平台。

更一般地，可以采用

\[
L_j^{GW}
=\Psi_j^E(EW_j)+\Psi_j^T(TW_j),
\tag{11}
\]

其中 \(\Psi_j^E,\Psi_j^T\) 在 \([0,p_j]\) 上非减、分段线性且在 0 处为 0。它允许窗口外加工量超过一定水平后使用不同边际费率，外侧仍受 \(EW_j,TW_j\le p_j\) 的截断影响。

当两侧费用对正加工量严格为正时，work 零费用要求整个加工区间都落在窗口内，即

\[
S_j\ge e_j,\quad C_j\le d_j
\quad\Longleftrightarrow\quad
C_j\in[e_j+p_j,d_j].
\tag{12}
\]

只有 \(D_j\ge p_j\) 时该区间才非空。不能把 work 的零费用区间也画成 \([e_j,d_j]\)。如果 \(D_j<p_j\)，任务可能同时含有 early work 和 tardy work。

## 2. 问题一：给定窗口的确定性并行机调度

制造商拥有 \(m\) 台同质并行机和一个外部生产服务商。每个任务的加工时间 \(p_j\) 与承诺窗口 \([\bar e_j,\bar d_j]\) 已给定。企业决定每项任务是内部加工还是外包，并为内部任务决定机器、加工顺序与执行时刻。

设外包集合为 \(O\subseteq J\)，内部集合为 \(I=J\setminus O\)。内部任务被划分为至多 \(m\) 条互不相交的机器序列。第 \(k\) 条序列记为

\[
\sigma_k=(j_{k1},\ldots,j_{kq_k}),
\]

其中每项内部任务恰出现一次，外包任务不出现在任何内部序列中。机器初始状态用虚拟任务 0 表示，\(C_0=0\)。若 \(j\) 紧随 \(i\)，需要序列相关 setup 时间 \(s_{ij}\ge0\) 和金额 \(g_{ij}\ge0\)；首任务使用 \(s_{0j},g_{0j}\)。对于每一条序列，令 \(j_{k0}=0\)，要求

\[
C_{j_{kh}}=S_{j_{kh}}+p_{j_{kh}},\qquad
S_{j_{kh}}\ge C_{j_{k,h-1}}+s_{j_{k,h-1},j_{kh}},
\quad h=1,\ldots,q_k.
\tag{13}
\]

不等式允许有意等待。现有论文还要求 setup 时间满足有向三角不等式 \(s_{ik}\le s_{ij}+s_{jk}\)，不对 setup 金额施加相同条件。

任务 \(j\) 内部完工的费用为给定非负、有限表示的分段线性函数 \(\phi_j(C_j)\)。主体情况为

\[
\phi_j(C_j)=
\alpha_j(\bar e_j-C_j)^+
+\beta_j(C_j-\bar d_j)^+.
\tag{14}
\]

外包任务不占内部加工和 setup 时间，其生产、交付影响按论文假设包含在外包报价中。设任务的外包基准报价为 \(q_j\ge0\)，集合 \(O\) 的实际外包支付为

\[
G\!\left(\sum_{j\in O}q_j\right),
\tag{15}
\]

其中 \(G\) 连续、非减、凹、有限分段线性，且 \(G(0)=0\)。凹性表示聚合数量折扣，无折扣时 \(G(q)=q\)。问题的完整目标为

\[
\min_{O,\sigma,S,C}
\left\{
\sum_k\sum_{h=1}^{q_k}g_{j_{k,h-1},j_{kh}}
+\sum_{j\in I}\phi_j(C_j)
+G\!\left(\sum_{j\in O}q_j\right)
\right\},
\tag{16}
\]

满足上述唯一加工方式、机器序列和时间约束。固定窗口不产生新的窗口分配决策。三张配图采用全部内部加工、无 setup 的共同示例，以突出窗口与偏差费用；计数和 work 图用于解释相应费用类型，不声称 Work 1 当前程序已经接入全部推广。

## 3. 问题二：可决策窗口的确定性并行机调度

制造商在 \(m\) 台同质并行机上加工全部任务。加工时间 \(p_j\) 已知，企业需要联合决定任务的机器分配、顺序、开始和完工时刻，以及每项任务自己的承诺窗口。与问题一不同，窗口不再是给定参数；与问题三不同，任务时长没有场景随机性。

全部任务恰好出现在一条机器序列中。时间约束采用式(13)；不考虑 setup 时令 \(s_{ij}=g_{ij}=0\)。Work 2 主稿允许保留确定性序列相关 setup 时间和金额，窗口结构分析不要求另外引入外包。

每项任务的窗口满足式(1)的 Model A；采用配套的 Model B 时，替换为式(2)。令 \(R\in\{ET,N,W\}\) 表示选择的费用类型，定义

\[
L_j^R=
\begin{cases}
\alpha_j(e_j-C_j)^++\beta_j(C_j-d_j)^+,&R=ET,\\
a_j^E\mathbf1\{C_j<e_j\}+a_j^T\mathbf1\{C_j>d_j\},&R=N,\\
\alpha_j\min\{p_j,(e_j-C_j+p_j)^+\}
+\beta_j\min\{p_j,(C_j-d_j)^+\},&R=W.
\end{cases}
\tag{17}
\]

按原稿费用口径，该联合问题为

\[
\begin{aligned}
\min_{\sigma,S,C,e,d}\quad &c(\sigma)+
\sum_{j\in J}\left[\rho_j e_j+\lambda_j(d_j-e_j)+L_j^R\right]\\
\text{s.t.}\quad
&\sigma\text{ 把全部任务划分为至多 }m\text{ 条互不相交的序列},\\
&C_j=S_j+p_j,\quad S_j\ge0,\\
&S_j\ge C_i+s_{ij},\quad(i,j)\text{ 为同一序列中相邻任务},\\
&S_j\ge s_{0j},\quad j\text{ 为机器首任务},\\
&(e_j,d_j)\in\mathcal W_j^A,\quad j\in J.
\end{aligned}
\tag{18}
\]

其中 \(c(\sigma)\) 是所选序列的确定 setup 金额，无 setup 时为 0；若稿件的虚拟终点弧带费用，也包含在 \(c(\sigma)\) 中。把式(3)换成式(4)即可得到配图采用的基准扣除版本，最优解不变。式(8)、式(11)可分别定义更一般的分级事件罚金和分段 work 费用，但不能把已有三类基础目标的全部结构结论不加证明地直接推广过去。

该问题允许在“承诺更早或更窄”和“执行时产生更多提前／拖期费用”之间权衡。允许窗口内完成的含义取决于指标：ET、计数只看完工点，work 还看整个加工区间。本文只描述联合决策问题，不在图中放入消元、定价或其他求解步骤。

## 4. 问题三：随机加工时间下的窗口分配与并行机调度

采用 Work 3 当前无 setup 主线。设有限场景集合为 \(\Omega\)，场景概率 \(\pi_\omega>0\)，且 \(\sum_\omega\pi_\omega=1\)。场景 \(\omega\) 下任务 \(j\) 的加工时间为 \(p_{j\omega}>0\)。同一任务放到任一机器上具有相同的场景加工时间，不同任务及不同场景的加工时间可以不同。

在场景实现前，企业确定任务机器分配、每台机器的顺序 \(\sigma\)，以及各任务的窗口 \([e_j,d_j]\)。这些决策在全部场景中共享。场景实现后，在既定分配和顺序下确定 \(S_{j\omega},C_{j\omega}\)。当前采用两阶段完全信息追索的解释；它不包含执行中逐步揭示信息时的在线改序决策。

每项任务仅有一个窗口变量对，满足式(1)，不带场景下标。若机器序列为 \((j_1,\ldots,j_q)\)，各场景时间满足

\[
\begin{aligned}
C_{j_r\omega}&=S_{j_r\omega}+p_{j_r\omega},\\
S_{j_1\omega}&\ge0,\\
S_{j_r\omega}&\ge C_{j_{r-1}\omega},\quad r=2,\ldots,q,
\qquad \omega\in\Omega.
\end{aligned}
\tag{19}
\]

允许场景内首任务前及任务之间等待，不直接收取等待费用。等待会影响当前和后续任务的完工费用；没有 makespan 或 overtime 目标。

定义

\[
E_{j\omega}=(e_j-C_{j\omega})^+,\qquad
T_{j\omega}=(C_{j\omega}-d_j)^+.
\tag{20}
\]

当前主线采用共同非负单位费率 \(\rho,\lambda,\alpha,\beta\)。完整目标为

\[
\begin{aligned}
\min_{\sigma,e,d,\{S_\omega,C_\omega\}}\quad
&\sum_{j\in J}
\left[\rho(e_j-A_j)+\lambda(d_j-e_j-D_j^{\min})\right]\\
&+\sum_{\omega\in\Omega}\pi_\omega
\sum_{j\in J}
\left[\alpha E_{j\omega}+\beta T_{j\omega}\right],
\end{aligned}
\tag{21}
\]

满足每个任务恰好出现一次、共同机器序列、式(1)和式(19)。承诺费用只收一次；场景执行费用按概率加权。不能让每个场景分别选择 \([e_{j\omega},d_{j\omega}]\)，也不能把场景排程图理解成场景实现后重新分配机器或排序。

共同费率表示统一服务标准，任务异质性仍由 \(p_{j\omega}\)、\([A_j,B_j]\) 和宽度界保留。外层 \([A_j,B_j]\) 限制承诺，不限制所有场景的实际完成；例如实际完成超过 \(B_j\) 时仍可行，但会相对于选定 \(d_j\) 支付拖期费用。

若定义随机计数或随机 work 版本，只需在式(21)中把执行费用换成 \(L_{j\omega}^N\) 或 \(L_{j\omega}^W\)。其中计数使用 \(C_{j\omega}\) 判断事件，work 使用场景实际时长：

\[
EW_{j\omega}=\min\{p_{j\omega},(e_j-C_{j\omega}+p_{j\omega})^+\},\qquad
TW_{j\omega}=\min\{p_{j\omega},(C_{j\omega}-d_j)^+\}.
\tag{22}
\]

式(8)、式(11)也可作同样的场景化定义。这些是本次配图所展示的目标推广，不属于当前线性 ET 计算结果的范围。已有 setup 扩展则把式(19)的相邻任务约束改为 \(S_{j\omega}\ge C_{i\omega}+s_{ij\omega}\)，并将共同序列的确定 setup 金额加入目标；它不替代无 setup 主体。

随机例子有三个等概率场景，完整开始时刻和加工时长保存在 `illustrative-data.json`。放大任务 \(J_3\) 的三个场景工时为 2、5、15，对应完工时刻 10、13、23；共享窗口始终为 [12,20]。右侧放大图为了单独比较费用，将工时固定为 5，并画出三个假设位置 \(C=9,13,23\)；它们不是随机主图三个场景的逐一复制，也不是同一任务同时加工三次。

\[
